# NetSentinel · 网络流量入侵检测与可视化分析系统

> 个人项目 · 2026.10 · 作者：沈炜丹（岭南师范学院 计算机科学与技术 2027 届）

## 项目背景
面向中小企业内网的轻量级入侵检测原型。针对校招中「银行 / 国企信息化 / 网络运维安全」岗位对
**网络与信息安全**能力的要求，用**纯 Python + 可解释规则引擎**实现一套覆盖「流量采集 →
特征聚合 → 多策略检测 → 告警可视化」的完整流水线，不依赖深度学习黑盒，每一步都可向面试官讲清楚。

## 技术栈
- Python 3.12（Anaconda）· NumPy（统计计算）
- 标准库 `csv` 合成流量与真实流记录解析
- 自研 SVG 图表报告（离线可看，可直接截图发 HR）

## 系统架构
```
gen_traffic.py   合成企业内网流量 + 四类带标签攻击事件（可复现，固定种子）
      │  flows.csv / auth.csv / ground_truth.csv
      ▼
detector.py      检测引擎：签名规则 × 统计异常双层
      │  alerts[]
      ▼
evaluate.py      按真值事件 1:1 匹配，计算 P / R / F1
      ▼
demo.py          生成自包含 HTML 报告（时间线 / 分布 / Top 主机 / 告警明细）
```

## 检测规则（可解释）
| 类型 | 判定逻辑 | 严重级 |
|---|---|---|
| **PORT_SCAN** 端口扫描 | 单源→单目标累计扫描端口数 ≥ 20 | 高 |
| **SYN_FLOOD** SYN 洪水 | 同一目标同一端口短时间 SYN≥40 且 ACK/SYN<0.2 | 紧急 |
| **BRUTE_FORCE** 暴力破解 | 单源对单服务失败登录 ≥ 8 次 | 高 |
| **EXFIL** 数据外泄 | 内网主机出站流量 z>2.5σ 显著偏离基线 | 紧急 |
| **ANOMALY** 异常兜底 | 主机总流量 z>3.5σ（签名层补漏，未产生误报） | 中 |

> 关键设计：SYN Flood 按「(目标,端口)」聚合，与端口扫描（多端口各少量 SYN）天然区分，避免规则打架。
